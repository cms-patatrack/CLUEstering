    SpatialGrid¶

    template<std::size_t Ndim, std::floating_point TData, concepts::device TDev>
    struct SpatialGrid¶

    Read-only description of the spatial grid built by the Clusterer in its last run.

    The grid is regular over the clustering space. The cells map each grid cell to the points it contains, in CSR form: the points of cell c are the values in [keys[c], keys[c + 1]), and the values are the positions of the points in the input given to make_clusters.

    Geometry:

    • along dimension d the grid covers [min[d], max[d]) with n_cells[d] cells of size cell_size[d]. A point goes in cell (coord - min[d]) / cell_size[d], truncated and clamped to [0, n_cells[d] - 1], so points outside the range fall in the border cells.

    • a periodic dimension covers one period, [0, period), and its coordinates are wrapped into that interval before binning.

    • a point within rounding error of a cell edge can be in either of the two adjacent cells, depending on how the compiler evaluates the division. Code that bins points again with this geometry must not expect to reproduce the cells of such points exactly.

    • the global cell index is row-major: the last dimension varies fastest.

    • in a batched run the grid is the same for all the batch items and the keys are concatenated, so the cells of item e have global indexes from e * total to (e + 1) * total - 1, where total is the product of n_cells.

    Note

    The object refers to the buffers of the Clusterer, which are overwritten by the next make_clusters call and freed when the Clusterer is destroyed.

    Note

    The grid is filled asynchronously on the clustering queue. Copy it on that same queue, or wait for it first.

    Note

    Use cells.extents() for the number of keys and values: the underlying buffers can be larger than the data they hold.

    Template Parameters:¶
    std::size_t Ndim¶

    The number of dimensions

    std::floating_point TData¶

    The floating-point type of the coordinates

    concepts::device TDev¶

    The device holding the cell associations

    Public Members¶

    const AssociationMap<TDev> &cells¶

    Map from each global cell index to the indexes of the points it contains.

    std::array<TData, Ndim> min¶

    Lower edge of the grid along each dimension.

    std::array<TData, Ndim> max¶

    Upper edge of the grid along each dimension.

    std::array<TData, Ndim> cell_size¶

    Size of the cells along each dimension.

    std::array<std::int32_t, Ndim> n_cells¶

    Number of cells along each dimension.

    std::array<bool, Ndim> periodic¶

    Whether each dimension is periodic.

    std::size_t batch_size¶

    Number of batch items in the last run, 1 for a run that is not batched.
